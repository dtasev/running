# Hansons Half Marathon 18-Week Training Plan (Peak ~45-55 Miles / 72-88 km)

This schedule applies the cumulative fatigue principle to the Half Marathon, capping the long run at 12 miles while developing threshold velocity via SOS workouts.

---

## 18-Week Schedule Overview
