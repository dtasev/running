# Norwegian Model Marathon 16-Week Training Plan

A structured 16-week periodized plan integrating weekly sub-threshold workouts and marathon-specific long runs.

---

## Weekly Microcycle Overview
- **Tuesday**: Threshold Day (Alternates Single Threshold or Double Threshold)
- **Thursday**: Steady Sub-Threshold / HM Tempo
- **Sunday**: Marathon-Specific Endurance Long Run with sub-threshold blocks
- **Monday, Wednesday, Friday, Saturday**: Zone 1 Easy running ($< 1.5\text{ mmol/L}$).
