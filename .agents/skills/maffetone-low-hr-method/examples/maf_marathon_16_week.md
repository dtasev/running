# Maffetone Marathon 16-Week Training Plan

This plan builds an aerobic engine via strict low-heart-rate running, integrating monthly MAF tests and race-specific aerobic long runs.

---

## Weekly Structure
- **All Runs**: Executed between $\text{MAF}-10$ and $\text{MAF}\text{ bpm}$ (e.g. 135–145 bpm).
- **Tuesday / Thursday**: Midweek aerobic base runs.
- **Saturday / Sunday**: Progressive weekend aerobic long runs.
- **Wednesday / Friday**: Active recovery runs or rest.
